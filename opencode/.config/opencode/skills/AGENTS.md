# OpenCode Skills

OpenCode-specific skills live here (`herd`, `memory`). Portable workflow
skills live in `~/dotfiles/agents/.agents/skills/` (shared with Codex) and
install into `~/.agents/skills/`, which OpenCode V2 discovers natively.

Skill routing is owned by `~/.config/opencode/AGENTS.md` — one router. Do
not duplicate routing here.
